# Git 训练评分标准

总分 100 分。验收人应结合仓库文件、Git 历史、远程分支和 Pull Request 进行评分；仅有最终文件但缺少要求的历史证据时不能得满分。

| 项目 | 分值 | 满分要求 |
| --- | ---: | --- |
| clone / add / commit 基础操作 | 20 | `profile.md` 内容完整；只暂存目标文件；提交信息正确；能解释工作区、暂存区和本地仓库 |
| branch 使用 | 20 | 分支命名正确；`branch.md` 完整；会使用 `switch` 并理解其与 `checkout` 的区别 |
| merge 操作 | 15 | 完成 fast-forward 与 merge commit 实验；图形化日志完整；能指出两种合并的差异 |
| 冲突解决 | 20 | 成功制造并解决真实冲突；无冲突标记残留；解决提交正确；能说明处理过程 |
| remote 协作 | 15 | 远程分支及 Pull Request 正确；PR 标题、正文完整；无直接推送 `main` 的行为 |
| commit 规范 | 10 | 提交粒度清晰、信息符合要求，无无关文件和敏感信息 |
| **总分** | **100** |  |

## 扣分参考

- 直接推送 `main`：remote 协作项不得满分，并要求说明风险。
- 修改他人目录：每次扣 5 分，并恢复无关改动。
- 提交信息不符合题目要求：每次扣 1 分，commit 规范项最低可扣至 0 分。
- 使用 `git add .` 提交无关文件：每次扣 2 分。
- 冲突文件仍含冲突标记：冲突解决项计 0 分。
- 只有口头说明、没有对应文件或历史证据：对应步骤不得分。
